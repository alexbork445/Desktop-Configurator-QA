# BUG-005: Регистрация пропускает 17-летнего

**Severity:** Critical | **Priority:** P1 | **Status:** Not run

**Окружение:** Windows 11, Chrome, RU

## Предусловия
Открыта форма регистрации, пользователю ещё нет 18.

## Шаги
1. Заполнить обязательные поля.
2. Поставить дату рождения так, чтобы возраст был 17 лет.
3. Новости не трогать.
4. Нажать регистрацию.

## Факт
Форма уходит либо показывает не-про-возраст ошибку, а блок 18+ не срабатывает.

## Ожидание
Регистрация отклонена с сообщением про совершеннолетие.

## Статус
План прогона, не прогнан. Скриншот из ТЗ — статичный, на нём этих действий не видно.

## Что дальше
По ТЗ открытый клуб «только совершеннолетним (≥18)». Тут противоречие с условием допуска.
