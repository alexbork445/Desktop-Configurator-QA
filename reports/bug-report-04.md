# BUG-004: Добавленную опцию можно добавить ещё раз после очистки поиска

**Severity:** Minor | **Priority:** P2 | **Status:** Not run

**Окружение:** Ubuntu 24.04 / Windows 11, RU

## Предусловия
Опция «Категоризация» уже добавлена, в списке серая.

## Шаги
1. В поиск ввести «Категоризация».
2. Очистить поиск.
3. Снова нажать на опцию в левом списке.

## Факт
Опция добавляется повторно, хотя уже есть в компоненте.

## Ожидание
Серая опция остаётся недоступной для повторного добавления независимо от фильтра.

## Статус
План прогона, не прогнан. Скриншот из ТЗ — статичный, на нём этих действий не видно.

## Что дальше
Проверить на билде: на скриншоте фильтрации нет, поведение воспроизводимо только в живом окне.
