# BUG-001: Обязательную опцию «Наименование» можно удалить

**Severity:** Critical | **Priority:** P1 | **Status:** Not run

**Окружение:** Windows 11, 1920x1080, RU

## Предусловия
Открыт конфигуратор, в компоненте есть обязательные «Наименование» и «Система координат модели».

## Шаги
1. В центральной области выбрать «Наименование».
2. Нажать удаление.
3. Если спрашивает — подтвердить.
4. Посмотреть правую панель BIM Свойства.

## Факт
Опция удаляется, из панели свойств исчезает.

## Ожидание
Удаление запрещено: либо действие недоступно, либо сообщение «опция обязательная».

## Статус
План прогона, не прогнан. Скриншот из ТЗ — статичный, на нём этих действий не видно.

## Что дальше
ТЗ явно говорит, что опции «Наименование» и «Система координат модели» не могут быть удалены. ТЗ перечитал — подтверждаю, тут баг по ТЗ, а не моя выдумка.
