# BUG-003: После удаления и повторного добавления опции значения свойств теряются

**Severity:** Major | **Priority:** P1 | **Status:** Not run

**Окружение:** Windows 11, 1920x1080, RU

## Предусловия
В компоненте есть необязательная опция, часть свойств заполнена.

## Шаги
1. Удалить заполненную опцию.
2. Добавить её снова из левого списка.
3. Открыть BIM Свойства.
4. Посмотреть значения.

## Факт
Значения вернулись пустыми, без предупреждения.

## Ожидание
Зависит от продукта: либо значения сохраняются, либо перед удалением предупреждение о потере. В ТЗ не написано — вопрос владельцу.
