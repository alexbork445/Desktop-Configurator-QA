## Что это по статусу

Билда нет, только скриншоты. Поэтому это **план прогона**, а не отчёт о выполнении.

В таблице Excel колонка «Статус» стоит `Not run` на всех строках. Настоящие результаты появятся, когда прогоню на живом окне. Фейковые `Passed` я не проставлял — на собеседовании это заметят быстрее всего.

## Что хочу прогнать в первую очередь

Пять проверок с высокой вероятностью проблемы. Описал на каких шагах ловлю:

| # | Проверка | На чём ловлю |
|---|---|---|
| 1 | можно ли удалить обязательную опцию «Наименование» | ТЗ прямо запрещает — быстрый тест |
| 2 | порядок опций в BIM Свойствах | тянуть опцию, сравнивать центр и правую панель |
| 3 | сохраняются ли значения после удаления + повторного добавления | ТЗ молчит, нужен ответ |
| 4 | не добавляется ли опция повторно после очистки поиска | поиск → очистить → кликнуть снова |
| 5 | пускает ли форму 17-летний | самое важное правило допуска |

Порядок выбран по плотности проверки, а не по severity: №5 уйдёт первым, потом №1, остальное — заодно.

Подробные шаги каждой — в `reports/`, та же структура, только статус «не прогнано».
