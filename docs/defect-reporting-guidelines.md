# Как оформляю баги

Каждый репорт — чтобы разработчик воспроизвёл без устных объяснений.

- ID
- заголовок: что + где + при каком условии
- severity / priority
- окружение (ОС, версия, разрешение, масштаб)
- предусловия
- шаги
- фактический результат
- ожидаемый результат
- скриншот/видео/лог
- статус

Примеры — в `reports/`. Учитывая, что приложения пока нет, часть репортов помечена как «проверить на билде».
