# Тест-кейсы на регистрацию

Полностью лежат в Excel, лист «Регистрация — тест-кейсы». Здесь ключевое.

Границы возраста — главное правило формы, поэтому гонял плотнее всего:

| ID | Сценарий | Ожидаем |
|---|---|---|
| REG-01 | пользователю ровно 18 | регистрация проходит |
| REG-02 | 19 / 30 / 50 лет | проходит |
| REG-03 | 17 лет | не пускает, ошибка про возраст |
| REG-04 | 17 лет и 364 дня | не пускает |
| REG-05 | сегодня ровно день 18-летия | пускает (вопрос: как считать, ниже) |
| REG-06 | дата рождения в будущем | режется, регистрация невозможна |

Дальше по форме:

| ID | Сценарий | Ожидаем |
|---|---|---|
| REG-07 | отправить пустую форму | ошибка у каждого обязательного поля |
| REG-08 | в поле только пробелы | считается пустым, ошибка |
| REG-09 | email user@example.com | принимается |
| REG-10 | user, user@, @example.com, user@example | ошибка формата |
| REG-11 | пробелы до/после email | либо чистит, либо ошибка — зависит от требований |
| REG-12 | уже зарегистрированный email | сообщение «уже используется» |
| REG-13 | пароль короче минимума | ошибка |
| REG-14 | пароль минимальной длины | принимается |
| REG-15 | пароль длиннее максимума | ошибка либо режется ввод |
| REG-16 | пароль и подтверждение разные | ошибка несовпадения |
| REG-17 | новости НЕ выбраны | регистрация всё равно проходит |
| REG-18 | новости выбраны | проходит, согласие сохраняется |
| REG-19 | дважды быстро жать кнопку | дубль аккаунта не создаётся |
| REG-21 | пройти Tab'ом, отправить Enter | фокус логичный, отправка однократная |
| REG-22 | засунуть `<script>alert(1)</script>` | скрипт не выполняется |

REG-20 (ошибка сервера), REG-23–30 (перезагрузка страницы, XSS-проверки, мобильный экран) — в Excel, тут не дублирую.
