# Чек-лист конфигуратора

Полный список — в Excel, листы «Конфигуратор — функциональный» и «Конфигуратор — нефункциональный».

## Функциональное

**Окно**

- [ ] открывается без ошибок, видны левая/центральная/правая части
- [ ] слева доступные опции, в центре добавленные, справа BIM Свойства

**Обязательные опции**

- [ ] «Наименование» и «Система координат модели» есть по умолчанию
- [ ] их нельзя удалить (кнопка удаления отсутствует или неактивна)
- [ ] их нельзя добавить ещё раз
- [ ] при переоткрытии сохраняются

**Добавление**

- [ ] доступная опция добавляется по клику
- [ ] появляется в центре и в BIM Свойствах
- [ ] в левом списке становится серой
- [ ] серую повторно добавить нельзя
- [ ] опция с несколькими свойствами — все свойства видны справа

**Удаление**

- [ ] необязательная опция уходит из центра и из правой панели
- [ ] снова становится доступной слева
- [ ] обязательные не удаляются
- [ ] удаление одной не трогает соседние

**Порядок**

- [ ] опции двигаются вверх/вниз
- [ ] порядок в BIM Свойствах меняется синхронно
- [ ] свойства внутри опции тоже двигаются
- [ ] после сохранения порядок сохраняется
- [ ] при переоткрытии не сбивается

**Поиск**

- [ ] полное название, часть названия, без учёта регистра
- [ ] кириллица
- [ ] нет результата — нормальное пустое состояние
- [ ] очистка возвращает полный список
- [ ] найденную уже добавленную опцию нельзя добавить заново

**Сохранение**

- [ ] новая конфигурация сохраняется
- [ ] отмена возвращает последнее сохранённое
- [ ] закрытие с несохранёнными изменениями предупреждает (если это есть в продукте)
- [ ] ошибка сохранения показывает сообщение и не врёт, что сохранилось

## Нефункциональное

- [ ] обычные операции без заметной паузы
- [ ] большой список не вешает приложение
- [ ] прогон подряд несколько раз не побит конфигурацию
- [ ] поддерживаемые разрешения не разваливают вёрстку
- [ ] масштабы 100/125/150/200% работают
- [ ] основные действия доступны с клавиатуры
- [ ] видимый фокус, логичный обход
- [ ] серое состояние различимо не только цветом
- [ ] длинное название не режется, есть tooltip
