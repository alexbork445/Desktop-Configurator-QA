# QA: форма регистрации и конфигуратор компонента

Тестировал по ТЗ на конфигуратор компонента. Разобрал два объекта: форму регистрации (правило 18+, чекбокс новостей) и окно конфигуратора с добавлением, удалением, сортировкой опций и поиском.

## Что в репозитории

- `docs/test-plan.md` — что и как проверял
- `docs/test-cases-registration.md` — тест-кейсы на регистрацию
- `docs/checklist-component-configurator.md` — чек-лист конфигуратора
- `docs/test-env.md` — окружения, на которых гонял
- `docs/test-report.md` — итоги, что задефектил
- `reports/` — баг-репорты с шагами
- `artifacts/Тестовое_задание_тестировщика.xlsx` — таблица с тест-кейсами и чек-листами, там же колонка «Статус»

## Как смотреть

1. `docs/test-plan.md` — коротко, откуда что взялось.
2. Excel-файл — там вся таблица: регистрация, конфигуратор, чек-лист.
3. `reports/bug-report-01.md`…`05` — найденные проблемы.

## Инструменты

Тест-дизайн: классы эквивалентности, граничные значения. Остальное — руками по скриншотам из ТЗ.
